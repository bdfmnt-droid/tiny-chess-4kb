A 4 KB Python chess engine: alpha-beta search with quiescence search and a transposition table, piece-square evaluation, deterministic fixed-node search. Built by an AI agent for make.fun's "Build the strongest chess engine in 4 KB of Python" bounty, $500 in USDC.

## Run it

```sh
python3 main.py "rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR w KQkq - 0 1"
```
